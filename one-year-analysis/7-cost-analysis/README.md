# Module 7 — Cost Analysis and Configuration Optimization

## Purpose

Translates the reliability matrix from Module 6 into a minimum-cost system
recommendation.  Given a reliability threshold (default 95 %) it evaluates
the total installed cost for every (panels, battery) configuration that meets
the threshold, and ranks them by total cost to identify the optimal build.

Cost components include hardware (pump, VFD, inverter, racking, wiring, drip
system, battery, extra panels), plus LTL freight shipping from San Francisco,
CA to Orlando, FL based on component weight.

---

## Script

### `cost_analysis.py`

```bash
# Default: 95% reliability, loads sweep CSV from 6-run-sims automatically
python cost_analysis.py

# Custom reliability threshold
python cost_analysis.py --reliability 90

# Sweep specific configurations (generates synthetic reliability if no CSV)
python cost_analysis.py --panels 10 12 15 18 20 --battery 1 2 3 4 5

# Show all valid configurations (not just top 5)
python cost_analysis.py --show-all

# Use a specific reliability matrix CSV
python cost_analysis.py --matrix-csv /path/to/reliability_matrix.csv

# Skip plot generation (faster for quick cost checks)
python cost_analysis.py --no-plots
```

### Typical workflow

1. Run the parameter sweep in Module 6 to generate a reliability matrix:
   ```bash
   cd ../6-run-sims
   python run_simulation.py --sweep-panels 10 12 15 18 20 --sweep-battery 1 2 3 4 5
   ```
2. Run this script — it picks up the matrix automatically:
   ```bash
   cd ../7-cost-analysis
   python cost_analysis.py --reliability 95
   ```

If no reliability matrix CSV exists, the script falls back to synthetic
(model-based) reliability estimates and prints a warning.  Results with
synthetic data show the correct cost structure but should not be used for
real decisions.

## Cost Model

### Solar panels

Panels up to 15 are assumed to already be on hand (cost = $0).  Additional
panels beyond 15 are priced at **$180 each** plus **$40/panel** of extra
racking.

### Fixed hardware (every configuration)

| Component | Estimated cost |
|---|---|
| Pump (1.5 kW nominal) | $1,000 |
| VFD (1.5 kW) | $450 |
| Hybrid inverter (3 kW) | $1,200 |
| Mounting / racking (≤15 panels) | $600 |
| Wiring + conduit | $500 |
| Drip irrigation system | $800 |
| Misc / contingency | $300 |

### Variable hardware

| Component | Unit cost |
|---|---|
| Extra solar panels (>15) | $180 / panel |
| Extra racking (>15 panels) | $40 / panel |
| LiFePO4 48 V battery | $350 / kWh |

### Shipping (San Francisco, CA → Orlando, FL)

LTL freight estimate.  Weight-based two-tier pricing:
- First 500 kg: $1.75/kg
- Above 500 kg: $1.40/kg
- 20 % fuel + handling surcharge on top
- Minimum charge: $200

Component weights used:
| Component | Weight |
|---|---|
| Solar panel (405 W) | 21.5 kg each |
| Battery (LiFePO4) | 11 kg / kWh |
| Hybrid inverter (3 kW) | 18 kg |
| Pump (1.5 kW) | 15 kg |
| VFD | 5 kg |
| Racking | 3.5 kg / panel |

To update any cost or weight, edit the constants at the top of `cost_analysis.py`.

## Plots

**C1 — Reliability Heatmap**
Grid of reliability values (%) with rows = panels and columns = battery
capacity.  Cells meeting the threshold are shown in bold.  Green = high
reliability, red = low.  Use this to see the trade-off between panels and
battery in achieving the target.

**C2 — Cost Heatmap**
Same grid layout as C1 but showing total system cost in USD thousands.  Cost
increases moving right (more battery) and upward (more panels, but only
for extra panels beyond 15).  Compare with C1 to find the sweet spot.

**C3 — Cost Breakdown (Top Configurations)**
Stacked bar chart for the top 6 configurations meeting the threshold, sorted
by total cost.  Each bar is segmented by cost category.  Reliability is
annotated above each bar.  Shows which cost drivers dominate and how the
balance shifts between configurations.

**C4 — Reliability vs. Cost Scatter**
Scatter plot of all configurations in the matrix.  X-axis = total cost, Y-axis =
reliability.  Green points meet the threshold; red points fall below it.
Configurations near the top-left corner of the green region represent the
best value (high reliability at low cost).  The dashed horizontal line marks
the threshold.

**C5 — Optimal Summary Card**
Single-page summary of the recommended configuration showing: panel count,
battery size, reliability, and total cost, with a full line-item breakdown and
a pie chart of cost allocation.  Suitable for printing as a project summary.
